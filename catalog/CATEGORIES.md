# Catalogue categories

Categories are facets, not project ideas. A category may have zero completed entries until a project in that area is actually built and documented.

| Category | Completed entries now |
|---|---:|
| Embedded foundations | 1 |
| IoT and sensors | 0 |
| Wireless and networking | 2 |
| Cybersecurity projects | 0 |
| Home automation | 0 |
| Smart devices and wearables | 0 |

A project can have more than one category only when the implemented and tested work genuinely spans those areas. Do not label a project as cybersecurity, IoT or home automation solely because it might be extended in that direction later.
